## Custom Design Path

Use this path when your design starts as a more complex custom structure in a mechanical CAD tool such as SolidWorks or FreeCAD.

## Typical workflow

1. Model the geometry in SolidWorks or FreeCAD.
2. Export the 2D outline or profile that should become the chip pattern to `.dxf`.
3. Import the `.dxf` file into LayoutEditor.
4. Scale, align, and clean up the imported geometry.
5. Add fabrication-friendly layers, labels, and alignment marks.
6. Verify spacing, snap points, and feature sizes before exporting the final layout for lithography/fabrication.
