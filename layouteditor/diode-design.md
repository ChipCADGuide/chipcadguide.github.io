# Diode Design in LayoutEditor (Manual Only)

This diode tutorial is intentionally manual and LayoutEditor-only.

## Steps

1. Create a new cell named `diode_1um_manual`.
2. Draw the active area rectangle.
3. Add two contact regions with symmetric placement.
4. Draw metal for both terminals.
5. Label terminals as `ANODE` and `CATHODE`.
6. Save/export as `diode_1um_manual.gds`.
