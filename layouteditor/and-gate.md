# AND Gate in LayoutEditor

## Steps

1. Create a cell named `and2_1um_manual`.
2. Place PMOS and NMOS devices from openCellLibrary.
3. Route inputs `A` and `B`.
4. Route output `Y` and rails `VDD`/`VSS`.
5. Label all top-level pins and check spacing.
6. Export `and2_1um_manual.gds`.
