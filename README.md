# chipcadguide.github.io

Beginner-friendly chip layout tutorial with dual tracks:
- **Track A:** Python-based flow
- **Track B:** LayoutEditor-based flow

Main tutorial content is in [`index.md`](./index.md).

Highlights:
- openCellLibrary in both tracks
- ~1 µm feature-size framing
- FET-based examples
- Step-by-step modules (diode, AND gate, multi-gate logic block, simple FET amplifier)
- Custom-device flow (microfluidics-style geometry via FreeCAD/SolidWorks -> DXF -> layout integration)
- Generous image placeholders for visual learning
